# Serviço e contrato HTTP — 17/09/2026

## Startup

O comando documentado é:

```powershell
uv run --frozen bentoml serve careerpath.service:CareerPathService --host 127.0.0.1 --port 3000 --do-not-track
```

Como o sandbox não permite criar o diretório padrão `C:\Users\MIGUEL\bentoml`,
esta coleta definiu `BENTOML_HOME=.bentoml` e executou o entry point instalado no
ambiente frozen. `.bentoml/` já é ignorado pelo Git.

```powershell
$env:BENTOML_HOME = Join-Path (Get-Location) '.bentoml'
.\.venv\Scripts\bentoml.exe serve careerpath.service:CareerPathService --host 127.0.0.1 --port 3000 --do-not-track
```

Trecho real do startup:

```text
2026-09-17T15:10:20-0300 [INFO] [cli] Starting production HTTP BentoServer from "careerpath.service:CareerPathService" listening on http://127.0.0.1:3000 (Press CTRL+C to quit)
2026-09-17T15:10:35-0300 [INFO] [entry_service:careerpath:1] Service careerpath initialized
```

O processo iniciado para a coleta foi encerrado após as chamadas. O teste E2E da
mesma execução também iniciou o serviço duas vezes pelo `uv run --frozen` e
confirmou predição após reinício.

cliente é o HTTP 400 esperado e testado.
